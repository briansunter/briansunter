## Start here

- 📚 **[Caliber](https://github.com/briansunter/caliber)** is a high performance web reader for your Calibre library. Cursor pagination and virtualized lists keep it quick even on million-book collections.
- 🍳 **[Cooklang Parser](https://github.com/briansunter/cooklang-parse)** is the TypeScript parser for Cooklang, the plain-text recipe language.

## Projects

### 🤖 AI & agent tooling

- 🃏 **[anki-ai](https://github.com/briansunter/anki-ai)** gives Claude 45 Anki tools over MCP.
- 🌐 **[ArcFetch](https://github.com/briansunter/arcfetch)** fetches a URL and hands back clean Markdown. Plain HTTP first, Playwright fallback for JS-heavy pages, and gates that toss out paywalls and login walls before they reach you (CLI + MCP).
- 🧠 **[Vannevar](https://github.com/briansunter/vannevar)** 🚧 does local, offline RAG search over Markdown. SQLite FTS5 keyword search and HNSW vectors, fused with Reciprocal Rank Fusion.
- 🔎 **[SearchThing](https://searchthing.briansunter.com)** runs semantic search over your own docs, with embeddings generated on-device via Transformers.js.
- 🗂️ **[UberSearch](https://github.com/briansunter/ubersearch)** is one CLI and MCP front-end for Tavily, Brave, Linkup, and self-hosted SearXNG, and it tracks your credits.
- 🎙️ **[Paratran](https://github.com/briansunter/paratran)** transcribes audio fast on Apple Silicon (CLI, REST, and MCP), built on parakeet-mlx.
- 📡 **[RSS AI](https://github.com/briansunter/rss-ai)** 🚧 is a CLI RSS/Atom reader with OPML, full-text search, content extraction, broken-link repair, and a TUI.
- 🪢 **[wraptc](https://github.com/briansunter/wraptc)** routes coding requests across Gemini, OpenCode, Qwen, and Codex, falling back automatically when one runs out.
- 🥋 **[Kungfu](https://github.com/briansunter/kungfu)** is a library of reusable Agent Skills any compatible coding agent can install and use.
- 🐾 **[PokeClaude](https://github.com/briansunter/pokeclaude)** is an MCP server for Pokémon TCG Pocket: search the card pool, find synergies, build decks.
- 🔖 **[raindrop-mcp](https://github.com/briansunter/raindrop-mcp)** is an MCP server for Raindrop.io bookmarks, collections, tags, and highlights.
- 🧰 **[z-cli](https://github.com/briansunter/z-cli)** is a CLI and MCP for Z.AI: image generation, OCR, vision, web search, and code research.
- 🧬 **[Verso](https://github.com/briansunter/verso)** 🚧 is a vector database for Bun, Node, and the browser, with HNSW indexing and Int8 quantization.

### 🖥️ Desktop & native apps

- 📰 **[CoolRSS](https://github.com/briansunter/coolrss)** 🚧 is a local-first RSS and read-it-later app (Tauri, Rust, React, SQLite).
- 🎧 **[Audiobook Player](https://github.com/briansunter/audio)** 🚧 streams audiobooks from Google Drive and runs on macOS, Windows, Linux, and iOS (Tauri, Rust, React).
- 📚 **[Caliber](https://github.com/briansunter/caliber)** is a web reader for your Calibre library, with EPUB and PDF readers built in.
- 🕰️ **[CuckooTimer](https://cuckootimer.com)** is a 3D cuckoo-clock timer for the macOS menu bar (Rust, Tauri, Three.js).

### 🎮 Games & graphics

- 🔫 **[Blackwater Rift](https://briansunter.github.io/blackwater-rift/)** is a monochrome top-down shooter for the original Game Boy, with a browser shell.
- 🦘 **[Pogo Panic](https://briansunter.github.io/pogo-panic/)** is a Game Boy arcade platformer built with GBDK-2020.
- 🛩️ **[TRAD Strike](https://briansunter.github.io/trad/)** is a Raiden-inspired vertical shooter in C99 on Sokol. The same binary runs native and in the browser.
- 🧱 **[Platform](https://github.com/briansunter/platform)** is a 2D platformer rendered with isometric 3D models (C99, Sokol, a tiny ECS), running native and in WASM.
- 🧩 **[c-ecs](https://github.com/briansunter/c-ecs)** 🚧 is a single-header C99 entity-component-system with fixed capacities and zero allocation.
- ⚛️ **[Quantum Engine](https://github.com/briansunter/quantum-engine)** 🚧 is a minimal, plugin-driven ECS game engine in TypeScript.
- 🕹️ **[Bevy Agent](https://github.com/briansunter/bevy-agent)** 🚧 is a Bevy plugin that drives a game as a deterministic sim an AI agent can step, snapshot, replay, and branch.
- 🔴 **[Connect Four](https://connectfour.briansunter.com)** is real-time multiplayer on a 3D board (React, Socket.io, Three.js).
- 🧍 **[3D Me](https://briansunter.github.io/3D-me/)** is a body-scanned 3D selfie loaded into a three.js scene.

### 🧰 Developer tools & infra

- 🌲 **[gitforest](https://github.com/briansunter/gitforest)** 🚧 is a TUI for managing dozens of Git repos.
- 💀 **[Deadman](https://github.com/briansunter/deadman)** is a dead-man's switch for Prometheus and Alertmanager, running on Cloudflare Workers and Durable Objects.
- 📶 **[Yuptime](https://github.com/briansunter/yuptime)** is a Kubernetes-native uptime monitor where monitors are CRDs and each check runs in a throwaway Job pod.
- ☁️ **[Oracle World](https://github.com/briansunter/oracle-world)** is a set of OpenTofu modules for Oracle Cloud's Always Free tier. One `apply` gives you a 4-core ARM box with 24 GB RAM.
- 📧 **[Subs](https://github.com/briansunter/subs)** is an email-signup API that writes straight to a Google Sheet. Turnstile blocks the bots, and there's no database to run.
- 💳 **[Typst Business Cards](https://github.com/briansunter/typst-business-cards)** is a set of business-card templates built with Typst.

### 🪶 Obsidian & Logseq plugins

- 📊 **[Obsidian CSV Editor](https://github.com/briansunter/obsidian-csv-editor)** 🚧 opens `.csv` files in a spreadsheet grid, with keyboard nav, range select, and copy/paste.
- 🌲 **[Obsidian Data Editor](https://github.com/briansunter/obsidian-data-editor)** 🚧 opens `.json` and `.yaml` in a visual tree editor, with schema validation and a source mode.
- 💡 **[Obsidian Insights](https://github.com/briansunter/obsidian-insights)** 🚧 surfaces live AI writing insights, connections, and counter-arguments as you write.
- ✅ **[Obsidian Schema](https://github.com/briansunter/obsidian-schema)** 🚧 validates note frontmatter against JSON Schema and reports problems in a sidebar.
- 🤖 **[Logseq GPT-3 Plugin](https://github.com/briansunter/logseq-plugin-gpt3-openai)** wires OpenAI text models into the Logseq editor.
- 🔌 **[Logseq MCP](https://www.npmjs.com/package/logseq-mcp)** hooks Claude into your Logseq graph: search blocks, draft daily notes, run Datalog.
- 📤 **[BlogSeq](https://github.com/briansunter/blogseq)** exports a Logseq page to clean Markdown and bundles every referenced asset alongside it.
- 📺 **[Logseq YouTube Captions](https://github.com/briansunter/logseq-get-youtube-captions)** grabs the captions for any YouTube link and pastes the transcript in place.
